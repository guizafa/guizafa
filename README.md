### About

Computer Science graduate from [UNIP](https://unip.br/). Most of my work falls into two buckets:

- Web SaaS: multi-tenant apps, admin panels, and clinic software with Next.js, Supabase, Stripe, and Vercel
- FiveM / cDev: Lua resources with QB, Qbox, and ESX bridges, plus NUI built in Svelte, TypeScript, and Vite

I'm also learning Three.js for 3D work in the browser.
